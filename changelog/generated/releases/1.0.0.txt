TypeSync 1.0.0 - First Working Stable Release
Important:
- This is treated as the first stable/working public version.
New Features:
- Core note/folder management with rich-text editing.
- Guest/local mode and cloud-backed account mode.
- Calendar, homework, and timetable productivity modules.
- Drag-and-drop, PDF support, local folder sync, and file export foundations.
- Theme customization, editor toolbar controls, and attachment workflows.
Fixes & Improvements:
- Major sync reliability and auth-flow stabilization before stable release.
- Build and CI hardening across Linux/Android/Web/Nix.
